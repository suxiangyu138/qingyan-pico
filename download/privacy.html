隐私说明

轻言 Pico · 最后更新 2026-11-19

我们收集什么

不收集任何可识别个人身份的信息。没有账号体系，没有广告 SDK，没有崩溃上报，也没有第三方统计脚本。

站点只在服务器本地记录几个计数：安装包下载次数、网页版打开次数、下载页访问次数。不记录 IP、不记录浏览器标识、不写 Cookie，也不在页面上对外展示，仅作者本人用来判断项目使用情况。

数据存在哪里

API Key、对话记录、记忆、个性化设置全部保存在你设备上的应用私有目录。图片缓存在应用缓存里。卸载应用会一并删除，删除后无法恢复。

请求发往哪里

唯一的外部请求是 DeepSeek 官方接口 api.deepseek.com，用于生成回答、联网搜索、解析文档与查询余额。请求由你的设备直接发出，不经过任何中转服务器。

费用

所有 Token 消耗按你自己的 DeepSeek API 账户结算，本项目不代收费用，也不共享密钥。

你的权利

随时可以在应用内导出全部数据为 JSON，或直接卸载删除。没有需要向开发者申请删除的云端数据，因为不存在云端数据。
