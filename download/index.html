轻言 Pico

2 MB 的 DeepSeek 轻客户端。自带 API Key，数据只存本机，绕开 C 端每日额度与 4 万字输入限制，上下文 1M。安卓装 APK，iPhone、鸿蒙与电脑用网页版，历史对话可以直接导入。

为什么是它

不受每日额度限制

官方 App 与网页版自 2026 年 11 月起限制每日对话额度、单次约 4 万字输入。这里用自己的 API Key 直连，按量计费。

对话留在本机

会话、记忆、图片只存设备本地。没有账号与云同步，删应用即清空，不存在「7 天不活跃就续不上」。

能力对齐官方客户端

深度思考（低/高/最高三档）、联网搜索、阅读链接、图片识别、PDF 与 Office 解析，全部走官方接口，模型 V4.1 Flash / V4 Pro。

用量透明

每条回答显示缓存命中率、输出速率与费用；顶栏实时显示上下文占用。累计花费单独记账，删会话、换版本都不清零。

历史对话可迁移

官方导出的整包 zip 直接选进「导入对话」，两千多个会话全量导入，按最近使用排序。

一个包，四种设备

安卓与鸿蒙 4 及以下装 APK；iPhone、鸿蒙 NEXT、电脑打开网页版添加桌面，界面与功能完全一致。

安装

1
下载安装包

点上方按钮，浏览器提示「可能有害」时选择仍然下载。

2
允许未知来源

打开文件后系统会提示，前往设置允许当前浏览器安装，再返回继续。

3
填入自己的 Key

首次打开填入 DeepSeek API Key，在设置里点「测试连接」确认可用。

iOS 安装

1
用 Safari 打开网页版

点上方「打开网页版」，必须是 Safari，微信内置浏览器不行。

2
点底部分享按钮

地址栏右侧或底部的方框箭头图标，菜单里选「添加到主屏幕」。

3
确认添加

桌面出现「轻言」图标，点开即全屏使用，首次进入填自己的 API Key。
