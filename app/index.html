新手引导

轻言只负责替你向 DeepSeek 的服务器发消息，所以要先用你自己的一把钥匙。下面几个词看懂，后面就都通了。

先弄懂这几个词

API 是什么
API 就是「给别人用的接口」。去餐厅吃饭，菜单给人看，后厨只收单子；API 就是那个收单子的窗口，程序把问题递进去，答案递出来。轻言用的是 DeepSeek 开放平台的那个窗口，不是官方 App 里的窗口。
API Key 是什么
窗口不认人，只认钥匙。API Key 就是这把钥匙，长这样 sk-3f9a…，一长串字母加数字。填进轻言，轻言才能替你发消息。
钥匙就是钱包：谁拿到谁花你的钱。不要发给别人，也不要截图发群里。
Token 是什么
Token 是计费单位，模型按它算钱。中文大约一到两个字算一个 token，一千字的文章差不多六百到八百个 token。你发的字和它回的字都要算。
DeepSeek 按每百万 token 计价，日常聊天一天通常几分钱到几毛钱。
上下文是什么
上下文是一次能记住多少内容。轻言支持 1M，大约相当于三四本长篇小说。顶栏能看到当前占用，超出后会自动丢掉最早的消息。
余额是什么
DeepSeek 是预付费，先把钱充进账户，用多少扣多少。余额用完就发不出消息，点顶栏的金额可以随时刷新。

五分钟开通

1
打开开放平台浏览器访问 platform.deepseek.com，用手机号或邮箱注册登录。是开放平台，不是 chat.deepseek.com 那个聊天网页。
2
充值左侧点「充值」，最低 10 元。先充最少的试，10 元够聊很久。
3
创建 API Key左侧点「API keys」，新建一个，名字随便起，比如 pico。
4
复制那串 Key点复制，拿到 sk- 开头的一长串。它只在创建时显示一次，关掉就看不到，丢了只能删掉重建。
5
填进轻言回到设置，粘贴到上面的输入框，点「测试连接」。能看到余额就通了，直接开聊。
第 5 步如果提示 401，多半是少复制了几位，或者这个 Key 已被删除。回平台重新建一个最省事。

出问题先看这里

提示 401、Key 无效
Key 没复制全、带了空格，或者已经在平台删了。重新复制整串，注意前后不要有空格。
提示余额不足
账户没钱了。去平台充值，充完点顶栏金额刷新一下。
提示请求太频繁
短时间发得太快，等十几秒再发。
图片或文件发不出去
图片最多 30 张，文档最多 3 个，单个不超过 30MB。PDF、Word、PPT、Excel、EPUB 和常见文本格式都能读。
换手机怎么搬
设置 → 存储 → 导出备份，把 JSON 发到新设备，再用「导入备份」恢复。图片原图不进备份。

数据在谁手里

Key、对话、记忆、图片都只存在你这台设备上。轻言没有服务器，不中转、不上报、不统计。唯一的对外请求是你自己发起的 api.deepseek.com。
